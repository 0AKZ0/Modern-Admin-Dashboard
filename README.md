# Modern Admin Dashboard

A responsive admin dashboard starter built with React, Vite and Tailwind CSS. It includes a KPI overview, activity feed, revenue visualization, and a compact project table using clearly labeled demo data.

## Stack
- React 19
- Vite 6
- Tailwind CSS 4
- Lucide React icons

## Getting started
```bash
npm install
npm run dev
```
Open the local URL printed by Vite.

## Scripts
- `npm run dev` — local development
- `npm run build` — production build
- `npm run preview` — preview the production build

## Customization
Replace the demo arrays in `src/App.jsx` with data from your API. Keep API credentials on the server; never place private keys in frontend environment variables.

## Notes
All metrics and activity entries are fictional sample data for UI demonstration. This starter does not include authentication or a real analytics backend.
